# Visual-response audit

Every control in the 104-lesson library was sampled at its two endpoints at a fixed animation phase. A numerical-only response is shown by live quantity bars and can be plotted in Live graph; it does not imply that the apparatus should physically change shape. This endpoint audit is not a visual review of every intermediate value.
